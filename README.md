# Routine Pie Planner

A hand-drawn style routine planner with daily, weekly, monthly and yearly pie wheels.

## Files
| File | What it is |
|---|---|
| `index.html` | The page layout |
| `style.css` | Look and feel |
| `config.js` | **Colours, doodles and starter plan. Edit this one for quick changes.** |
| `app.js` | How the app works (wheels, saving, ticks) |
| `manifest.webmanifest` | App name and icon, so phones and laptops can install it |
| `sw.js` | Lets the app open without internet |

## Your data
Your plan is saved in the browser of each device, not in this repository.
Use **Download backup** / **Load backup** at the bottom of the app to move it between devices.
